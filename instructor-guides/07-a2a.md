# A2A Protocol on AgentCore

**Doc**: [Deploy A2A servers in AgentCore Runtime](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-a2a.html)

## Setup

```bash
mkdir ~/a2a-experiment && cd ~/a2a-experiment
agentcore create \
  --name my_a2a_server \
  --framework Strands \
  --model-provider Bedrock \
  --protocol A2A \
  --defaults
cd my_a2a_server
```

## Run Locally

```bash
agentcore dev
```

Opens AgentCore inspector. Agent listens on port 9000.

## Test with curl

Send JSON-RPC message:
```bash
curl -X POST http://localhost:9000/ \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": "req-001",
    "method": "message/send",
    "params": {
      "message": {
        "role": "user",
        "parts": [{"kind": "text", "text": "what is 101 * 11?"}],
        "messageId": "12345678-1234-1234-1234-123456789012"
      }
    }
  }' | jq .
```

Fetch agent card:
```bash
curl http://localhost:9000/.well-known/agent-card.json | jq .
```

**Summary**: A2A is Agent-to-Agent protocol. Agents discover each other via Agent Cards and communicate via JSON-RPC over HTTP. Same Strands agent, different serving protocol.
